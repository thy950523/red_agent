# 路人鱼风格 A｜双图固定提示词 v3

## 输入

只上传两张图片，按以下顺序：

1. **图一：真人照片**，提供构图、姿势、表情、完整头发与发型、服装、物品和场景内容。
2. **图二：路人鱼图片**，提供鱼类面部与身体造型、所有外露部位的形态、头身比例、肤色及二维动画绘画风格。

`style_a_example.png` 是效果样例，不需要作为输入上传。

## 直接复制的提示词

请将图一的真人照片完整转化为一张风格 A 的二维卡通插画。**画面仍然是图一的画面，只是人物变成按照图二绘制的比奇堡路人鱼。**

**图一控制内容和布局：**保持图一的画幅比例、裁切、景别、镜头角度、人物在画面中的位置与大小、身体姿势、手势、头部朝向、表情、服装、随身物品，以及背景主要物体的相对位置。图一拍到哪里就画到哪里，不扩图，不强制补出全身。

**图一的头发必须完整保留：**保留图一的发色、分缝、发际线、头发长度、发量、发束走向及具体发型，包括辫子、刘海或扎发等可见细节。把这些头发用图二的平面卡通画法重新绘制，自然长在鱼角色的头部上。不得用图二的帽子遮住或替换图一的头发，也不得擅自改变发型。

**图二控制鱼类造型和画风：**以图二原有的鱼头轮廓、眼睛大小与位置、眉毛、鱼嘴、肤色、颈部连接方式，以及头部高度相对躯干的比例为准。不要为迁就图一的人脸或发型而改成人类脸型，也不要任意放大或缩小鱼头。图一真人的表情仅作为轻微调整依据：只调整鱼眼视线、眉毛弧度和鱼嘴嘴角，让鱼脸传达相近的情绪；鱼的五官样式与布局始终优先采用图二。

**所有外露部位都要鱼类化：**凡图一中露出的手、手臂、肩、颈、腿或脚，在结果中都应成为图二同一角色的鱼类皮肤和结构。手保持图一的手势和触物位置，但画成简化的鳍状鱼手，不能出现真人掌纹、五根真实手指或人类关节。手臂、腿等保持图二的肤色、轮廓线与简化程度，和鱼头属于同一个角色。让鱼角色做图一的动作；不要照搬图二的姿势、帽子、服装或背景。图一的服装与物品用同一套卡通画法重绘。

**固定风格 A：**可爱、明快的手绘二维电视动画；清晰而略有手绘起伏的深色轮廓线；鲜明协调的大色块平涂；每个主要形体最多一层简单的硬边阴影；大而清楚的卡通眼睛；没有写实纹理、复杂光影或 3D 体积感。将图一的背景也按这套画法重绘，保留图一的地点与空间布局，可少量加入海底世界的装饰元素。

**严格避免：**真人脸贴在鱼身上、真人面部比例、真实皮肤或五官、人类手掌和真实手指、真人身体加鱼鳞或鱼尾、半写实鱼人、美人鱼尾巴、鱼头与身体比例不一致、图二的帽子挡住头发、丢失或改动图一的发型、照搬图二的服装和姿势、改变图一构图、照片质感、3D 渲染、油画笔触、塑料光泽、文字、水印、界面元素。

## 复用规则

- 每次只换图一真人照片；图二路人鱼图片和整段提示词保持不变。
- 新照片中的头发、服装与物品必须随图一更新；风格 A 的线条与上色规则保持不变。
- 若平台支持固定模型、参考强度与 seed，尽量复用相同设置。画幅比例仍以每次的图一为准。
- 若头发丢失，追加：`优先恢复图一的完整发型，按原位置、分缝、长度和发束重新画在鱼头上；图二的帽子不得出现。`
- 若结果偏真人鱼，追加：`除头发、服装和物品外，所有面部与身体结构必须完全采用图二的二维卡通鱼造型。`
- 若鱼脸偏离图二，追加：`恢复图二的鱼头轮廓、眼睛与鱼嘴布局；仅微调眼神、眉弧和嘴角来表达图一的情绪。`
- 若手臂或腿像真人，追加：`将所有外露的肢体重画为图二同一条鱼的鳍状结构和统一肤色，并恢复图二的头身比例。`
